# 智绘工坊（Nano Banana Studio）非管理员快速上手

> 一页内看完即可使用（面向普通用户/访客）。

## 1. 登录 / 访客
- **登录**：输入账号密码 → “Sign In”。
- **访客**：点 “Continue as Guest”。访客的历史只保存在当前浏览器。

## 2. 图像工坊（单图）
1) 选 **模型 / 学科 / 画幅 / 画质**
2) 写提示词 → 可点 **AI 润色**
3) 可选：上传最多 4 张参考图
4) 点 **“立即生成”**（或 Ctrl + Enter）

生成后可 **下载 / 重绘 / 快速修改**。

## 3. 音频工坊
- 语音合成（TTS）：选 **模型 + 音色** → 填文本 → 生成。
- 音乐/音效：选时长 → 写描述 → 生成。

## 4. 视频工坊
- 选 **模式 / 模型 / 画幅 / 时长 / 分辨率**。
- 文生视频：直接写提示词。
- 图生视频：先上传 1 张参考图。
- 生成完成后右侧可播放并下载。

## 5. 数字人（在视频工坊里切换“数字人”）
- 必需：**头像图 + 驱动音频**。
- 头像图：jpg/png/bmp/webp，≤10MB，最小 400px。
- 音频：mp3/wav，≤15MB，时长 ≤20s（建议 ≤15s）。

## 6. 批量工厂（多素材队列）
1) 选素材类型（图/音/视频/数字人）
2) 设置统一参数（模型、画幅等）
3) 每行一条内容 → “加入队列”
4) 点“全部开始”执行 → 可“暂停”

提示：图生视频需要参考图；数字人需要头像。

## 7. 画廊
- 按学科过滤；可勾选“我的创作 / 精选”。

## 8. 个人 Key（解决额度/模型问题）
路径：**全局设置 → 用户设置**
- 添加个人 Key（用途、模型、API Key 可按需填写）
- 仅当前浏览器生效；优先于系统 Key 使用。

## 9. 常见提示
- **请先配置模型**：联系管理员或添加个人 Key。
- **额度不足**：联系管理员或添加个人 Key。
- **未授权/请登录**：重新登录或补充个人 Key。
